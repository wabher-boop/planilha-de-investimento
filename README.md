Nesta planilha de investimentos você pode ter uma previsão de patrimônio a um determinado prazo que você quiser, 
tendo uma sugestão de percentual de investimentos conforme cada perfil de investidor.
Caso queira também há uma planilha que você pode calcular o tempo necessário para acumular recursos para tirar férias ou 
compra de um veículo conforme o aporte indicado
